# Scrapstar

Top-down 2D space shooter: fly with inertia, fight pirates, loot wrecks, trade at stations and build a career from a scrap-heap pilot to a legend of the sector. Inspired by *Space Pirates and Zombies*.

- [Design document (RU)](docs/DESIGN.md) — core loop, ship modules, factions, careers and five visual style mockups.

## Status

Concept stage — nothing to run yet.
